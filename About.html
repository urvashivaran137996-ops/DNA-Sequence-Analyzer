About Project

DNA Sequencing Analyzer

A Web Technology based Bioinformatics project.

🧬 Project Overview

DNA Sequencing Analyzer is a web-based application designed to perform basic analysis of DNA sequences.

The application accepts a DNA sequence and calculates nucleotide composition, sequence length, GC content and AT content.

💻 Technologies Used

  • HTML5
  • CSS3
  • JavaScript
  • Bootstrap 5

🎯 Project Objectives

✔ Validate DNA sequences

✔ Calculate nucleotide counts

✔ Generate sequence transformations
