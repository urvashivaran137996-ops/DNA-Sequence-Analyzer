About DNA Sequence Analyzer

DNA Sequence Analyzer is a simple web-based Bioinformatics project developed using HTML, CSS and JavaScript.

Objectives

  • Analyze DNA sequences.
  • Count A, T, G and C nucleotides.
  • Calculate nucleotide percentages.
  • Calculate GC Content.
  • Calculate AT Content.

Technologies Used

  • HTML5
  • CSS3
  • JavaScript
